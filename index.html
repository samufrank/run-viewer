One row per published run, newest first. sites: source sites (the regions DETECT finds, one RTL expression each) the approved plan names over sites offered to the planner; hovering gives the same two counts with each site multiplied by the elaborated instance count of its module (a packed block holds up to one such instance per term of its mode). rewrites: for a run with the objective loop switched on, the rewrites it built and measured, 0 when the planner declined the first plan; a dash for a run without the loop. Hovering gives the revision the loop kept, where it kept one rather than the first pass. loop stopped by: planner declined (the first plan, or a revision), no gain beyond noise (a revision did not lower the product by more than the minimum gain), cap reached (every allowed revision spent), no loop; older records also show trigger quiet, dry run and revision failed. It is the record's ended_by where the record has it; hovering says when it is read from the run's outcome (a declined first plan, so the loop never started) or from an older record's rewrites and cap. period and used area: VPR's critical path delay and total used logic block area for the kept rewrite, each the median over the loop's seeds where the loop ran, else the one recorded flow; hovering a used area shows the VPR log it was read back from where the record was made before the run wrote that figure, or why there is none. agent min: the agent calls' own seconds from the call ledger, summed, in minutes. VTR min: the run's wall clock (its start and finish timestamps) minus the agent minutes; the record does not time the VTR flows on their own, so this also holds the synthesis-only checks and the framework's time between calls. verified: the kept rewrite's checks from the run record, as one label: proven when the LEC closed, simulation under assumption when the simulation passed without a closed proof and the plan stated a bound it rests on, simulation only when it stated none (the two results are in the hover text); a star marks a result read from the hand-kept equivalence line of descriptions.yaml, for runs whose record carries none, where a stated bound is not on file.

Layouts: a run is compared only with the unmodified design under its own VPR settings, named after the layout (auto = minimum-width search, auto-sized layout, seed 1; koios_extra_small = width 300, koios_extra_small, seed 1; koios_small = width 300, koios_small, seed 1; koios_medium = width 300, koios_medium, seed 1; koios_large = width 300, koios_large, seed 1). Hovering a run id shows its hand-kept description, and hovering an area-delay figure shows both products and the baseline's layout. Generated 2026-10-05 14:40 -0700.
