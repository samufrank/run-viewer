So a value sampled at edge k must be held in a soft register for exactly one edge; no port of this mode provides that delay. 17 bits (a+b exactly, both unsigned 16-bit) is the narrowest such register, because add_out_reg must be bit-exact: when the mode leaves eltwise-add without a reset, P is the accumulator's starting value for the next P <= P + M edge (lines 2807–2808 feed back add_out_reg), and the testbench's verdict build does not force a reset on a mode change.
  2. Putting the 17-bit adder after the register instead of before it is a losing trade. Restoring soft a_flopped/b_flopped (32 flip-flops) and adding a_flopped+b_flopped combinationally into C costs about 32 extra BLEs per instance (≈2700 BLEs ≈ +15% total area, since the adder's LUTs can no longer pack with the sum register's flip-flops), and it moves a 4-level adder into the C→P stage, which already spends a fixed 0.060 + 2.159 = 2.219 ns. At the routing delays actually measured on that adder in the kept candidate (0.868 / 1.702 / 0.660 / 1.389 ns of wire across four levels), that stage would land near or above the present 5.357 ns period rather than below the 4.66 ns needed to pay for the extra area.
  3. No second block helps. The multiplier cannot form a+b (M = A2·B2 only), A:B, the carry and the cascade ports are outside this mode, and both operands cannot be packed into the 27-bit A port (16+16 > 27). Giving each MAC a second block to do the eltwise add would add 84 DSP tiles (+2.13e7, +42% area) to save ≈143 CLBs (4e6) — far worse. Nor can two MACs share one block: all 84 processing_element instances (lines 2599–2662, instantiated across systolic_pe_matrix) run every cycle in parallel.
  4. The remaining soft logic in seq_mac is not block-expressible. The mac_out saturating downcast (lines 2823–2835) and the out register (lines 2838–2844) are nonlinear and sit behind P; the block exposes no pattern-detect or saturation output in this mode.
  5. The measured period is no longer set by block-reachable arithmetic in a way this mode can shorten. The reported path is four soft LUT levels of which 4.62 ns of 5.38 ns is routing; its logic depth is already what Yosys/ABC produce for a 17-bit sum, and depth is not the dominant term.
